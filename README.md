# Mi Portafolio Web & Currículum Vitae (CV)

Proyecto web profesional desarrollado con **HTML5, CSS3 y JavaScript**, listo para desplegarse gratuitamente en **GitHub Pages**.

## 📁 Estructura de Archivos
- `index.html`: Estructura principal del currículum y portafolio.
- `style.css`: Estilos visuales modernos, diseño adaptable (responsive) y soporte para modo oscuro.
- `script.js`: Interactividad (cambio de tema claro/oscuro, año dinámico y formulario).
- `foto-perfil.jpg`: *(Debes subir tu propia foto con este exacto nombre)*

## 🚀 Cómo publicarlo en GitHub Pages
1. Crea un nuevo repositorio público en tu cuenta de **GitHub** (con tu nombre y apellido).
2. Sube los archivos (`index.html`, `style.css`, `script.js`, `README.md` y tu foto llamada `foto-perfil.jpg`).
3. Ve a **Settings** (Configuración) > **Pages** en el menú lateral izquierdo.
4. En **Build and deployment > Branch**, selecciona `main` (o `master`), carpeta `/ (root)` y haz clic en **Save**.
5. Espera 1 a 2 minutos y recarga la página para obtener tu enlace público de GitHub Pages.
